About Keystride

Keystride is a minimal, keyboard-focused typing speed test. Type the given text as quickly and accurately as you can — your words-per-minute, accuracy, and consistency are measured in real time.

How WPM is calculated

Net WPM = (correct characters ÷ 5) ÷ minutes elapsed. Raw WPM uses total characters typed regardless of correctness. Accuracy is correct characters divided by total characters typed.

Running as a full product

This build is a complete, working client: typing engine, timer, statistics, themes, settings, personal bests and a local leaderboard, all persisted in your browser's local storage — no account needed. A production version with real accounts and a global leaderboard would add a small server (FastAPI + a database) that stores users and test results and issues the leaderboard from there. That backend is a separate deployment step beyond a single static file — ask and it can be scaffolded as a downloadable project.

Privacy

Nothing you type or any of your statistics leave this browser. Everything is stored in local storage on this device only.
